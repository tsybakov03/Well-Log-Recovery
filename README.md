# Прогноз значений акустического каротажа (АК)

Проект посвящен восстановлению пропущенных данных АК в скважине 2PO на основе данных опорной скважины 11PO с использованием методов машинного обучения.

## Задача
1. Обучить модель на данных скважины **11PO** (ГК, НГК, ПЗ, АК).
2. Прогнозировать кривую АК для скважины **2PO**.
3. Оценить точность прогноза на проверочных данных.

## Данные
- `11PO.xlsx`: Опорная скважина (ГК, НГК, ПЗ, АК).
- `2PO.xlsx`: Целевая скважина для прогноза.
